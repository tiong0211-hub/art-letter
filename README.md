# art-letter
그림 한 점, 마음 한 장. ART LETTER 공개 미술 매거진.

이 저장소는 **공개 출력 전용**입니다. `index.html`, `publication.json`, `.nojekyll`은
비공개 저장소 `art-newsletter`의 발행 컨트롤러(GitHub Actions)가 검증된 회차로 생성해 커밋합니다.
직접 고치지 마세요. 다음 발행 때 덮어써집니다. 집필·검증·발송 절차는 `art-newsletter`의 `WRITING.md`와 문서를 보세요.

- `comments-worker/`: 독자 댓글 API (Cloudflare Workers + D1). 배포 방법은 그 폴더의 README.
